# ЦЕНТР УПРАВЛЕНИЯ "ЗЕМЛЯ"


## ПРИЕМНИК (РЕСИВЕР):
    - при получении начала пакета отпраяляет строку "Start packet: --" (где -- это HEX-адрес купола)
    DOM_1_ADDRESS   0x15
    DOM_2_ADDRESS   0x16
    DOM_3_ADDRESS   0x17
    DOM_4_ADDRESS   0x18
    - Дальше начинает отпраялять пакет побайтно.
    - '\n' Символ конца пакета
