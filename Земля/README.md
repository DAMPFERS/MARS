# ЦЕНТР УПРАВЛЕНИЯ "ЗЕМЛЯ"


## ПРИЕМНИК (РЕСИВЕР):
- при получении начала пакета отпраяляет строку "Start packet:-" (где - это байт HEX-адрес купола)
DOM_1_ADDRESS   0x15
DOM_2_ADDRESS   0x16
DOM_3_ADDRESS   0x17
DOM_4_ADDRESS   0x18
- Дальше начинает отпраялять пакет побайтно.
- Конец пакета 3 байта 0xFF
- Есть 2 типа сообщеницй (текстовое и параметрическое)
 -> если первый байт пакета 0хFE, то этот пакет параметрический (каждый байт это зачение параметра). Сейча парсится только 2 параметра (потребление, генерация)
 -> если первый байт пакета отличается от 0хFE, то это текстовое сообщение (байтовая последовательность интерпретируется как строка в кодировке utf-8)
