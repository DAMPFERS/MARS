# КУПОЛ СВЯЗИ

Занимается отправкой данных через лазер (протокол NEC). Устройство принимает даныые от Главного купола по USB Type B.
Устройство сохраняет все полученные байты в буффер. При чтении байта '\n' (символ конца пакета) устройство отправляет весь буффер по NEC и очищает буфер.


Управление: Arduino Uno
Напряжение питания: 5В
Максимальный размер передаваемой посылки: 127 Байт
